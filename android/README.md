# Galaxy S25 / Health Connect
기존 웹 UI를 유지하면서 Android Health Connect 데이터를 네이티브 브리지로 전달합니다.

- Samsung Health: 설정 > Health Connect에서 데이터 공유 허용
- Google 및 기타 앱: Health Connect에 기록된 데이터를 동일하게 읽음
- InBody: InBody 앱이 Health Connect에 체중/체지방을 기록하면 자동 유입
- InBody 직접 OAuth 연동은 InBody API 자격정보 발급 후 추가 가능

읽기 항목: 혈당, 체중, 체지방률, 걸음 수, 운동 세션, 총 소모 칼로리.
